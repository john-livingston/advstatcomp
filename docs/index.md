# Advanced Statistical Computing with Python

This site presents the material from [Advanced Statistical Computing](https://bookdown.org/rdpeng/advstatcomp/) by Roger Peng, originally written in R. Best efforts have been made to faithfully reproduce it in Python using NumPy, SciPy, and Matplotlib.

## Chapters

1. [**Introduction**](chapters/ch01_introduction.ipynb) — Linear models, optimization transfer, textbooks vs. computers
2. [**Solving Nonlinear Equations**](chapters/ch02_solving_nonlinear_equations.ipynb) — Bisection, rates of convergence, functional iteration, Newton's method
3. [**General Optimization**](chapters/ch03_general_optimization.ipynb) — Steepest descent, Newton direction, quasi-Newton, conjugate gradient, coordinate descent
4. [**The EM Algorithm**](chapters/ch04_the_em_algorithm.ipynb) — Exponential families, canonical examples, minorizing functions, missing information, acceleration
5. [**Integration**](chapters/ch05_integration.ipynb) — Laplace approximation
6. [**Independent Monte Carlo**](chapters/ch06_independent_monte_carlo.ipynb) — Random number generation, non-uniform sampling, rejection sampling, importance sampling
7. [**Markov Chain Monte Carlo**](chapters/ch07_markov_chain_monte_carlo.ipynb) — Metropolis-Hastings, Gibbs sampler, convergence monitoring, simulated annealing
